# Smart Window design workbench

For Firefox **AI Window / Smart Window** — specs, PRDs, patterns, prototypes, motion, stakeholder docs.

## Read first

1. **Skill:** `.cursor/skills/smart-window-design/SKILL.md` (or `~/.cursor/skills/smart-window-design/SKILL.md` when installed globally)
2. **References** (in skill folder `references/`):
   - `product-context.md` — product framing
   - `design-system.md` — tokens, components
   - `prd-surface-map.md` — eng-ready surface specs
   - `ux-motion-foundations.md` + `motion-landscape.md` — motion behavior

## When to use

- Smart Window / AI Mode / browser AI UX
- Motion design, transitions, thinking states, AI presence
- Prototypes and conviction calls on AI browsing patterns

## Not for

- Nova desktop chrome only (no Smart Window) — use [design-system skills](https://github.com/FirefoxUX/ai-native-knowledge-hub/tree/main/skills/design-system) or `~/.cursor/skills/nova-classic/`
- Fenix / Android — use `firefox-mobile-android` DESIGN.md
- Generic a11y pass — use `accessibility` skill
