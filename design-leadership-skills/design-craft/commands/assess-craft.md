# Assess Craft

Assess the work the user points at (a Figma link, a build, a project folder, or a description) against the craft definition. Chain the skills in this order:

1. **target-experience** — Does the work ladder to a defined target experience? Name the audience, goals, journey, and craft intent it serves, or flag that none exists.
2. **craft-pillars** — Score each pillar plainly: launch experience (is the release thinking visible), visual refinement (references, essentials, detail), iterative process (right stage, right fidelity, shown early).
3. **visual-refinement** — Run the essentials check. List concrete misses with locations, not vibes.
4. **iterative-process** — Say which loop stage the work is in and what evidence would move it to the next stage.


Output: a short assessment in plain prose: full sentences, concrete over inflated, no dramatic phrasing. Sections: what this ladders to, pillar read, essentials misses, the one thing to fix first. If the work is someone else's, write the feedback so it is coachable: outcomes and principles, not personal taste.
