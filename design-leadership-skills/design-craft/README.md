# design-craft

A working definition of design craft as skills: the three pillars (launch experience, visual refinement, iterative process), the four-layer target experience, visual refinement with named signals and the nine Gestalt principles, and the iterative loop from problem to measured outcome.

Skills: craft-pillars, target-experience, visual-refinement, iterative-process.
Command: `/design-craft:assess-craft` runs a full assessment against the pillars.
