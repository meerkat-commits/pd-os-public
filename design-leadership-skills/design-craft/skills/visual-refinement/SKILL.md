# Visual Refinement
You raise visual quality the way Brooke's craft practice does: wide references, named signals, essentials before flourish.

## Competitor UX Teardowns
1. Identify best practices in companies solving similar problems, direct and indirect.
2. Identify common elements or features that are driving decisions.
3. Create a repository of inspiration the team can return to.
4. Full modality, focused flows, real world impact: tear down complete journeys, not screenshots.

## Signals Method
For each reference, name the signals worth stealing, in a short list. Examples from Brooke's own audits: Verizon (bold colors, animation, cross platform, brand, systems), NASA+ (knowledge gap analysis, competitive analysis, bold colors, systems thinking), Cash App (illustrations, 3D treatments, physical/digital, textures, animations). A reference without named signals is decoration.

## Essentials Check (before any flourish)
- Gestalt principles (full set below); start with the five in Brooke's deck: closure, proximity, continuation, similarity, figure and ground.
- Layout and placement, font size readability, touch targets, error handling, QA pass.
- Consistency with the design system; deviations are deliberate and registered.

## The Nine Gestalt Principles (reference: gestaltprinciples.com, Jake Zuke)
1. **Similarity** — elements that look alike are perceived as related; patterns and groupings read instantly.
2. **Continuity** — eyes follow smooth paths; aligned or flowing elements guide attention effortlessly.
3. **Proximity** — objects placed close together are perceived as related; grouping and hierarchy become clear.
4. **Figure-ground** — a focal figure distinguished from its background lets key content stand out.
5. **Common fate** — elements moving together are perceived as a group; motion is a relationship tool (this is the principle behind good micro-interaction design).
6. **Closure** — gaps get filled to complete shapes; you can communicate with minimal detail.
7. **Symmetry and order** — symmetrical elements are seen as belonging together; balanced groupings cohere.
8. **Prägnanz** — simpler, clearer forms win; reducing complexity raises comprehension.
9. **Common region** — elements inside a shared boundary or background read as related; cards and panels work because of this.

When critiquing, name the principle a layout violates rather than saying it "feels off." The point of the vocabulary is coachable feedback: users should understand a layout with minimal cognitive effort, and each principle is a lever for that.

## Working Norms
- Go wide and think through multiple design iterations; divergent then convergent.
- Open the aperture past direct competitors to experiences solving similar problems.
- Show work early and often; invite XFN partners and leadership into the conversation.
