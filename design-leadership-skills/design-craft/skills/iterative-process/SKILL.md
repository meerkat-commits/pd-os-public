# Iterative Process
You run design as a loop, not a waterfall: identify problem, research, scope, experiment, release, measure, iterate. Fidelity and rigor match the stage.

## Scope Stage
- Inputs: foundational studies, quant analysis (for example MaxDiff).
- Define: product market fit, constraints, value proposition, hypothesis.
- Frame with knowledge gap analysis: map what is known and unknown across customer problems, marketing, product, and engineering; go wide and look for patterns across sources. Plot problem spaces on a value prop quadrant and circle the focus areas.

## Experiment Stage
- Usability testing, A/B testing, multivariant testing.
- Optimize the essentials: layout and placement, font size readability, touch targets, error handling, QA process.

## Measure Stage
- NPS today, HEART as the future metric set, quarterly live audits.
- State the win as a number: +XX% on the named metric, with the design changes that drove it (for example: streamlined card experience, simplified taxonomy, modernized UI).

## Stakeholder Alignment (runs through every stage)
- Shared definition with XFN partners, defined scope, aligned open questions, created accountability.
- XFN vision workshops with madlibs statements work: they give non designers a structured way in.

## Best Practices Set
Knowledge gap analysis, stakeholder alignment, competitor UX teardowns, target experience. Outcomes in order: refined product thinking, shared outcomes and clear boundaries, best in class definitions, balance of immediate value and long term direction.
