# Firefox voice & tone

Use this when writing for Firefox / Mozilla audiences.

## Qualities

- **Genuine**: plainspoken, human, specific. No corporate fog.
- **Playful**: light touch, clever not goofy. Don’t undercut serious moments.
- **Fiery**: principled and bold when it matters (privacy, user agency). Avoid anger.

## Defaults for exec + stakeholder comms

- Start with a crisp TL;DR.
- Make the user impact concrete.
- If there’s a risk, name it and show the mitigation.
- End with the decision/ask + timing.

## What to avoid

- buzzwords and “AI-y” filler
- hedging for no reason
- long windups before the point
