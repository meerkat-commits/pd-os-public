# Context library

Stable context that changes slowly (the stuff you don’t want to re-explain every session).

Suggested files:
- `stakeholders.md`
- `product.md`
- `principles.md`
- `writing-style.md`
- `design-md/` — Stitch-style `DESIGN.md` specs for agents (e.g. Firefox Android); see `design-md/README.md`
- `process/` — team workflows and operating playbooks (async design review, **critique prep**)
- `imports/` — pointers to imported/extracted knowledge from other sources

Tip: if you already have equivalents under `data/knowledge/`, you can copy them here over time.
