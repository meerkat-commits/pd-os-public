## Firefox Mobile Experience Vision 2026 (synthesized)

Source: `work/mobile-dau-triage/Experience_Vision_2026.md` from `VibeCoding-BK`.

### North star

If Firefox ceased to exist tomorrow, what would users meaningfully lose—and what would they replace easily?

Vision: Firefox Mobile becomes the browser users **choose** (not just try) because it’s fast, reliable, feels like theirs, and makes trust visible.

### Reality (Day 0 → Day 1 retention cliff)

- New users do meaningful things on Day 0 (search, media), but they don’t commit.
- The core problem is **habit formation** and **switching cost**, not basic usability.

### Pillars

1. **Utility browser → enduring relationship**
2. **Make trust experiential** (privacy you can feel)
3. **Build emotional attachment** (a browser that feels like mine)

### Five hypotheses to move DAU (with “what to measure”)

1. **Engineer the second session** → % returning within 24h
2. **Fix media reliability** → media error rate; D1 retention delta (error vs no-error)
3. **Increase session depth** → % open 2+ tabs OR return to previous page within Day 0
4. **Win default** → default-set rate; D7 retention (default vs non-default)
5. **Make discovery stick** → discovery CTR; retention delta for engagers vs non-engagers

### Differentiation themes called out

- Real add-ons on mobile (Android)
- Visible tracker blocking (privacy you can see)
- Choice: search + AI provider
- Cross-device sync without ecosystem lock-in
- Customization that sticks (themes/wallpapers/tab groups)

### “Pressure test” guidance

Separate:
- **Retention track**: second session, depth, default, media reliability, cross-device habit
- **Insight track**: surveys, reporting, feedback mechanisms (valuable, but not the DAU lever)
