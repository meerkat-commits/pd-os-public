## Project Nova — brief

Source: `work/project-nova/context.md` from `https://github.com/meerkat-commits/pd-os

### Problem

Project Nova is a comprehensive redesign initiative to redefine Firefox’s look, feel, and overall user experience in 2026.

- **Who**: younger/prospective users and long-time Firefox users
- **Why now**: positioned as a 2026 company priority with cross-functional execution underway

### Goals

- Deliver a modern, intuitive, distinctly Firefox design refresh
- Improve first impressions for younger users while remaining familiar/trustworthy for existing users
- Improve discoverability and usability of most-used browser features

### Scope (current)

In scope (now): Chrome, Sidebar, Search, New Tab, Smart Window, Onboarding, Private Window, Credential Management.

Out of scope (for now): fully specified 2027 scope; detailed per-feature sequencing across all surfaces until handoff.

### Operating model (cadences)

- Design sprints (1–2x weekly) to demo progress and refine specs
- Program sync (biweekly) to track blockers/dependencies/asks
- Product Review 1: design readiness gate before development start
- Product Review 2: implemented build + UX QA gate before Nightly exposure

### Success metrics (status)

Numeric KPI targets are not yet set. Current described gates emphasize review readiness and implemented build validation before Nightly exposure.
